五大功能域

平台看全局、队列跑业务、内核做复用、服务管交付

M1 · 平台管理

参数 1 / 2 / 3 / 4 / 5 / 6 / 7平台层
  • 机构管理：机构与机构用户全生命周期、管理员设置、启停用、Excel 导入
  • 课题管理：课题属性、研究设置、进度、锁定；观察型课题自动挂载队列模块
  • 分中心管理：主数据维护；课题内重设编码与计划入组数
  • 人员与角色：分中心人员进出、角色绑定、四维权限
  • 平台工作台：多课题入组、进度、质询、近一周详情
  • 文档管理：文件/文件夹、批量上传、类型与检索
核心价值
多队列/多课题的公共底座，资源与权限隔离
关键设计
课题即容器；研究类型决定模块挂载；平台工作台与队列工作台分工
主要用户
平台管理员、机构管理员、PI

M2 · 队列运营

Q1–Q4 + 参数 18队列层单队列操作台
  • 队列工作台：新建档案、查重、档案、样本单上传；入组与待办概览
  • 建档管理：知情同意上传、对象状态枚举、关键日期、双方/家庭结构、批量建档
  • 重复建档查询：证件号/姓名+生日组合查重、疑似列表、合并或关联
  • 档案管理：多维检索、CRF 提交状态矩阵、快捷导出、档案操作
  • 对象登记：登记入组、批量导入；与档案 1:N 关联
核心价值
回答「一个队列每天怎么运转」，把高频动作放在一个操作台
关键设计
档案（家庭）1:N 对象；建档即查重；档案列表用状态矩阵替代逐个点开
主要用户
建档员、CRC、PI、档案管理员

M3 · 队列配置

参数 8 / 9 / 10 / 15 / 16 + E3 + Q5/Q6队列层 + EDC 内核
  • 问卷配置：设计器、题目光型、校验、共享数据元；复制生成版本；填写角色
  • 随访计划：活动、主干/分支、时间点、窗口期、角色权限、启用锁定
  • 样本管理：时点 × 类型矩阵、采集/处理暂存、入库登记与审核、库位与流转
  • 队列设置：建档字段映射、双方结构、状态枚举、查重规则、样本字典、编码规则
  • 模板与数据元：共享/私有模板、使用次数与关联表单、导入导出
核心价值
把「某个队列的研究设计」变成可复制的配置包
关键设计
配置优先；问卷版本化；样本按「时点 × 类型」组织；内核能力不单独建入口
主要用户
建库人员、DM、样本管理员、PI

M4 · 数据采集与质量控制

参数 17 / 19 / 20 / 21 / 22 / 23 + E1 / E2队列层 + 内核
  • 对象与访视：患者/访视列表、9 种活动状态、访视详情、研究标签
  • 数据采集：填写/保存/提交/分享/打印、附件、备注、质询留言
  • 质询闭环：访视质询 + 我的质询，更新类/方案修改类，表单级锁定
  • 超窗与脱落：统一时间轴计算；脱落原因与操作人追溯
  • 任务日历：随访任务聚合，一键进入采集
  • 双录入 / 随机发号：按课题开关挂载，盲底与仲裁留痕
核心价值
数据进入系统的主战场，也是质控发生的现场
关键设计
状态机驱动；提交前规则校验；质询-锁定-解决闭环；超窗单一计算源
主要用户
研究者、CRC、CRA、DM

M5 · 统计交付与集成

参数 11–14 / 24 / 25 + E4服务层
  • 队列统计：入组趋势、性别、年龄、省份；分中心/质询/表单统计
  • 数据导出：条件→公式→格式；快捷导出类型；异步任务
  • 导出记录中心：导出人、类型、时间、文件、下载次数
  • 数据审核：导出申请 → 通过/驳回 → 下载，未通过不可下载
  • HIS/LIS 集成：患者主索引、就诊、检验申请与结果、字典同步
核心价值
数据出域的安全闸门与科研价值出口
关键设计
统计口径前置；导出即留痕；审核与下载联动；接口幂等与手工兜底
主要用户
PI、CRA、DM、统计人员

队列增强 Q1–Q6 与配置化

把单队列系统的页面抽象为可配置能力，而非写死某个研究主题

Q1 队列工作台

新建档案、查重、档案、样本单上传四个高频入口；入组数、表单完成率、待办聚合。

Q2 建档管理

知情同意、对象状态、关键日期、双方/家庭结构；创建即生成档案编号，支持批量建档。

Q3 重复建档查询

证件号、姓名+出生日期组合查重；疑似列表可合并或关联；保存时自动触发。

Q4 档案管理

多维检索、CRF 状态矩阵、七类快捷导出、查看/编辑/采集/脱落。

Q5 问卷配置

设计器、校验、共享数据元、复制版本、批量发布、填写角色（医生/对象/关联对象）。

Q6 队列设置

建档、查重、样本、问卷、编码的统一配置中心，新队列复制即用。
